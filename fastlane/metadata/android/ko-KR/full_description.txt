WakeUpScreen은 알림이 도착하는 순간 화면을 부드럽게 켜 주는 오픈소스 Android 앱입니다. 클라우드도, 군더더기도, 타협도 없습니다.

주요 기능:

• 즉시 화면 켜기 — 알림이 도착하는 순간 화면이 켜집니다. 휴대폰이 책상 위에 놓여 있어도 중요한 소식을 놓치지 않습니다.

• 주머니 모드 — 휴대폰이 주머니나 가방 안에 있는 것을 지능적으로 감지해 화면을 켜지 않습니다. 꼭 필요한 곳에서 배터리를 아낍니다.

• 앱 필터 — 어떤 앱이 화면을 켤 수 있는지 직접 선택합니다. 주의를 기울일 대상을 완전히 제어할 수 있습니다.

• 다크 모드 — AMOLED 디스플레이에 잘 어울리는 아름다운 다크 인터페이스. 눈에도 배터리에도 부담이 없습니다.

• 인터넷 불필요 — 모든 동작이 기기 안에서만 이루어집니다. 수집하는 데이터도, 접속하는 서버도 없습니다. 개인정보는 완벽하게 보호됩니다.

• 가벼움 — 최소한의 용량과 무시할 수 있는 수준의 배터리 사용. Kotlin으로 만들어져 네이티브 성능을 그대로 냅니다.

작동 방식:

1. 설치 후 알림 접근 권한을 허용합니다. 필요한 권한은 이것 하나뿐이며, 데이터는 기기를 떠나지 않습니다.
2. 어떤 앱이 화면을 켤 수 있을지 선택합니다. 중요한 메시지는 통과시키고 소음은 걸러 냅니다.
3. 일상에 집중하세요. WakeUpScreen은 백그라운드에서 조용히 실행되며, 알림이 오면 화면을 켜고 주머니 안에서는 꺼진 채로 둡니다.

추가 기능 (모두 켜고 끌 수 있음):

• 사용자 지정 화면 켜기 시간
• 방해 금지 모드 인식 — 방해 금지 모드가 켜져 있는 동안 화면 켜기를 중단
• 원하는 시간대를 지정할 수 있는 수면 모드
• 지속 알림 필터 — 음악, 내비게이션 같은 장시간 지속 알림은 건너뜀
• 충전 중에만 켜기 필터 — 기기가 충전 중일 때만 화면을 켬
• 채널 정보(중요도, 소리, 진동)를 포함한 알림 로그
• 알림 이벤트 진단을 위한 기능 테스트 페이지
