# 변경 이력

WakeUpScreen의 주요 변경 사항을 버전별로 정리한 문서입니다.

---

## [4.0.0]

### 추가
- 홈 화면에 마지막으로 화면 켜기에 성공한 시점("방금 전", 몇 분/몇 시간/며칠 전)이 표시됩니다. 알림 로그에서 바로 읽어오며, 탭하면 로그가 열립니다
- 수면 시간대를 원하는 요일에만 적용할 수 있으며, 매일 / 평일 / 주말 프리셋을 제공합니다. 자정을 넘기는 시간대는 시작한 날 저녁에 속하므로, 금요일 23:00 - 07:00은 여전히 토요일 아침까지 적용됩니다. 기존 시간대는 계속 매일 적용됩니다
- 새 규칙 "배터리 부족 무음": 배터리가 지정한 기준치(5-50%)보다 낮고 충전 중이 아니면 알림이 화면을 켜지 않습니다. 충전 중에는 항상 통과합니다
- 새 규칙 "엎어놓기 무음": 휴대폰이 화면을 아래로 향해 놓여 있는 동안 — 주머니 모드가 근접 센서로 감지하는 것과 같은 방식으로 가속도 센서가 감지 — 알림이 화면을 켜지 않습니다
- "야간 붉은 빛": 수면 시간대에 완전한 어둠 대신, 어두운 붉은 빛(최소 밝기, 검은 배경)을 잠시 표시할 수 있습니다. 당직 중이거나 아기가 있는 분을 위한 기능입니다. 붉은색은 어둠에 적응한 눈을 가장 덜 방해하기 때문이며, 로그에는 별도 상태로 기록됩니다
- 주의력 통계: 화면이 켜진 것과 30초 이내에 기기가 잠금 해제된 것, 두 가지 사건만으로 전부 기기 안에서 집계하여, 최근 30일 동안 화면만 켜고 결국 확인되지 않는 앱을 보여주고, 가장 심한 앱은 한 번의 탭으로 블랙리스트에 추가할 수 있습니다. 알림 내용은 절대 읽지 않습니다
- 설정 내보내기 및 가져오기: 시스템 파일 선택기를 통해 JSON 파일로 저장/복원하며, 새 권한은 필요 없습니다. 파일 형식에는 버전 번호가 담겨 있어, 이전 빌드는 더 새로운 설정을 그냥 무시하고, 더 새로운 형식의 파일은 반쯤 적용되는 대신 명확한 안내와 함께 거부됩니다
- 앱 내 변경 이력: 업데이트 후 첫 실행 시 무엇이 바뀌었는지 짧은 요약을 보여줍니다 — 최신 버전만이 아니라 건너뛴 모든 버전을 다룹니다. 설정 → 정보 → 업데이트 내역에서 언제든 다시 열 수 있으며, 업데이트로 추가된 설정 항목에는 방문하기 전까지 작은 점이 표시됩니다

### 변경
- 새로 추가된 두 규칙은 다른 모든 규칙과 마찬가지로 알림 판정 과정 다이어그램과 알림 로그에 표시됩니다
- 사용자 지정 화면 켜짐 시간이 잠금이 이미 해제된 상태에서는 화면을 끄지 않습니다: 켜짐 시간 도중에 잠금을 해제했거나 잠금 화면이 "없음"으로 설정되어 있으면, 화면을 잠그지 않고 시간이 끝납니다. 이전에는 잠금 해제 브로드캐스트를 놓치면 사용 중인 휴대폰이 잠길 수 있었습니다
- 사용자 지정 화면 켜짐 시간의 최솟값이 5초로 변경되었습니다(기존 3초). 위의 잠금 상태 확인이 일부 기기에서 신뢰할 수 있으려면 화면이 켜진 직후의 시간이 필요하기 때문입니다. 기존의 더 짧은 설정은 자동으로 5초로 올라갑니다
- 화면 켜짐 시간 지정: 접근성 권한이 없으면 눈에 띄는 빨간 경고로 표시되며, 스위치를 켠 채 권한 없이 페이지를 나가면 지금 켤지 그냥 나갈지 묻는 대화 상자가 나타납니다

### 참고
- 새 권한 없음
- 이 버전에서 요일 제한 없이 저장한 수면 시간대는 3.2.0에서도 읽을 수 있습니다. 특정 요일로 제한된 시간대는 이전 버전에서 잘못 해석되는 대신 무시됩니다

## [3.2.0]

### 추가
- 수면 모드에 여러 시간대를 하나씩 추가하고 삭제할 수 있어, 밤 시간대와 낮잠 시간대를 함께 둘 수 있습니다
- 수면 시간대를 정시 단위가 아닌 분 단위로 설정합니다
- 수면 시간 페이지가 하루를 24시간 링으로 보여줍니다. 수면 시간대는 회색으로 표시되고, 현재 시각이 표시되며, 0, 6, 12, 18시에 눈금이 있습니다
- 시간대를 추가할 때 기존 시간대와 비교하여, 겹침을 조용히 허용하는 대신 충돌하는 시간대의 이름을 알려줍니다

### 변경
- 색상 체계를 Material 3 기반으로 재구축했습니다. 값을 하나하나 손으로 쓰는 대신 브랜드 색상에서 전체 톤 범위를 생성하고, 라이트와 다크가 각각 M3가 규정한 톤을 읽으므로 두 테마가 더 이상 어긋날 수 없습니다
- 상단 바가 그라데이션 대신 단색을 사용합니다. 상태 표시줄의 색상과 아이콘 밝기는 현재 페이지를 따릅니다: 홈 히어로 영역은 짙은 그라데이션을 유지하고, 나머지는 라이트/다크 테마를 따릅니다
- 카드, 검색 필드, 상단 바가 M3의 서피스 레벨을 사용하여 다크 모드에서도 배경과 구분됩니다
- 24시간 링이 0부터 23까지 모든 시각에 레이블을 표시합니다. 이전에는 0, 6, 12, 18만 표시했습니다
- 수면 시간대는 시작 시각부터 종료 시각 직전까지 적용됩니다. 02:00 - 04:00은 03:59에 끝나므로, 한 시간대가 끝나는 시각에 다른 시간대가 정확히 시작하도록 두 시간대를 맞붙일 수 있습니다
- 기존의 단일 시간대는 업그레이드 시 자동으로 변환되며 동작은 그대로 유지됩니다
- "지속 알림 최적화"는 "진행 중 알림 차단"으로, "급진적 지속 감지"는 "상주 알림 차단"으로 이름이 바뀌었습니다. 두 항목 모두 각각 무엇을 차단하는지, 서로 어떻게 다른지 설명하는 "?" 버튼이 있습니다
- 설정을 일반, 고급, 진단, 정보로 재편했습니다. 일반에는 언어와 새 다크 모드가, 고급에는 알림 판정 과정과 화면 켜기 규칙 페이지가, 진단에는 화면 켜기 테스트와 로그 바로가기가 있습니다
- 새 다크 모드 설정에 세 가지 옵션이 있습니다: 시스템 설정 따르기, 라이트, 다크. 기본값은 시스템 설정 따르기이므로 업그레이드해도 화면 모습은 바뀌지 않습니다
- 화면 켜기 시간과 앱 필터(필터 모드, 화이트리스트, 블랙리스트)가 설정 홈에서 화면 켜기 규칙 페이지로 이동했습니다. 이제 이 페이지가 화면이 켜질지 여부를 결정하는 모든 항목을 다룹니다
- 여러 항목의 이름을 실제 하는 일에 맞게 바꿨습니다: "고급 설정"은 "화면 켜기 규칙"으로, "차단 체인"은 "알림 판정 과정"으로, "기능 테스트"는 "화면 켜기 테스트"로, "현재 모드"는 "필터 모드"로 바뀌었습니다. 이름만 바뀌었을 뿐 모든 설정 값은 유지됩니다

### 수정
- "급진적 지속 감지"(설정 → 화면 켜기 규칙)가 잘못된 설정 키에 저장되던 문제를 수정했습니다: 이 스위치를 켜고 끄면 일반 "지속 감지" 설정이 몰래 바뀌었고, 정작 스위치 자체는 저장되지 않아 페이지를 다시 열 때마다 켜짐으로 되돌아갔습니다. 이제 두 스위치는 서로 독립적이며 올바르게 저장됩니다

### 참고
- 급진적 지속 감지는 이 수정 이전에는 사실상 항상 켜져 있었고 기본값도 켜짐이므로, 업그레이드해도 알림 필터링은 달라지지 않습니다
- 급진적 스위치를 조작한 적이 있다면, 일반 "지속 감지" 설정이 모르는 사이에 바뀌었을 수 있습니다. 설정 → 화면 켜기 규칙에서 두 스위치를 한 번 확인해 보시기 바랍니다

## [3.1.1]

### 변경
- 이제 Android 16(API 36)을 대상으로 합니다. Android 16 시스템 이미지에서 검증했습니다: 화면 켜짐 시간 지정, 접근성 화면 잠금 동작, 권한 없는 대체 방식 모두 이전과 완전히 동일하게 동작합니다
- 보조 페이지가 앱 자체의 슬라이드 전환 대신 Android의 예측형 뒤로 가기 애니메이션을 사용합니다. Android 16 대상 변경에 따른 시각적 변화일 뿐, 뒤로 가기 동작 자체는 그대로입니다

### 참고
- 새 권한 없음, 기능 변경 없음
- 새로운 16 KB 메모리 페이지 크기를 사용하는 기기 이미지에서 검증했습니다

## [3.1.0]

### 기능
- "반복 알림"을 추가했습니다(설정 → 고급 설정): 읽지 않은 알림이 남아 있는 동안 5–60분 간격으로 화면을 다시 켜고, 알림이 정리되는 즉시 멈춥니다. 간격과 한 묶음당 최대 알림 횟수를 설정할 수 있으며, 수면 모드, 방해 금지 모드, 주머니 모드, 충전 중에만 켜기, 앱 필터가 모두 여전히 우선합니다. 진행 중 알림은 읽지 않은 알림으로 세지 않습니다
- 반복 알림에 의한 화면 켜짐이 알림 로그에 기록되며, 기능 테스트에서 간격을 기다리지 않고 즉시 한 번 실행해 볼 수 있습니다
- "사용자 지정 화면 켜기 시간"을 추가했습니다(설정 → 사용자 지정 화면 켜기 시간): 시스템의 화면 자동 꺼짐에 맡기는 대신, 화면을 3, 5, 10, 15 또는 30초 동안 켜 두었다가 끕니다. 화면을 끌 때는 선택 사항인 접근성 서비스를 통해 시스템 자체의 화면 잠금 동작을 사용하며, 화면 내용은 전혀 읽지 않습니다

### 변경
- 사용자 지정 화면 켜기 시간은 기본적으로 꺼져 있고 꺼진 동안에는 아무것도 하지 않으므로, 기존 설치는 이전과 완전히 동일하게 동작합니다 — 이전 구현은 웨이크 락을 즉시 해제했고 설정한 값을 적용한 적도 없었습니다

### 참고
- 새 권한 없음. 반복 알림은 부정확 알람을 사용하므로 Doze로 인해 몇 분 늦어질 수 있습니다
- 사용자 지정 화면 켜짐 시간은 기기가 잠금 해제되거나 화면이 꺼지면 조기에 취소되며, 통화 중에는 절대 화면을 끄지 않습니다

## [3.0.6]

### 변경
- `FOREGROUND_SERVICE_SPECIAL_USE` 권한을 제거했습니다. 화면 켜기는 시스템이 자동으로 바인딩을 유지하는 알림 리스너에 의존하므로, 특수 용도 포그라운드 서비스는 핵심 동작에 실제로 필요하지 않았습니다.
- 이 권한을 사용하던 유일한 기능인 "상주 알림(서비스 유지)" 설정을 제거했습니다. 배터리 관리가 공격적인 기기에서는 대신 이 앱을 배터리 최적화에서 제외해 주세요.

## [3.0.5]

### 기능
- "업데이트 확인" 페이지를 추가했습니다(설정 → 정보). Google Play, F-Droid, GitHub 옵션과 현재 설치된 버전을 보여줍니다. 인터넷 권한은 필요 없습니다 — 선택한 스토어나 페이지를 열기만 합니다.

### 수정
- Android 15 이상에서 엣지 투 엣지 / 안전 영역 레이아웃을 수정했습니다: 뒤로 버튼이 닿지 않던 문제, 제목이 상태 표시줄이나 카메라 컷아웃에 가려지던 문제가 사라졌고, 하단 내비게이션과 목록이 제스처 바를 피해 표시됩니다.

## [3.0.4]

### 수정
- 릴리스 빌드에서 알림 로그가 항상 "알 수 없는 이유"로 표시되던 문제를 수정했습니다 — 차단 이유를 난독화된 클래스 이름이 아니라 안정적인 식별자에서 가져오므로, 실제 이유(방해 금지, 충전, 수면 모드 등)가 올바르게 표시됩니다
- 상주 알림 스위치가 앱이나 서비스를 재시작하지 않아도 즉시 적용됩니다

### 개선
- 인식되지 않는 차단 이유는 "알 수 없는 이유"로 뭉뚱그리지 않고 로그에 그대로 표시하여, 문제를 진단할 때 정보가 사라지지 않습니다

## [3.0.2]

### 주요 변경
- Jetpack Compose로 UI를 전면 재구축했습니다
- 완전히 새로운 비주얼 디자인 시스템(Material 3 Periwinkle Bloom 테마)
- 새 페이지: 알림 로그, 기능 테스트, 피드백
- 다국어 지원 확대
- Android 14/15 호환성

### UI 및 디자인
- 대규모 아티스틱 UI 리디자인 — 새벽의 어두운 숲 테마
- 대규모 아티스틱 UI 리디자인 — Periwinkle Bloom M3 테마
- 홈과 설정 화면을 Jetpack Compose로 다시 작성
- 모든 보조 페이지를 Jetpack Compose로 다시 작성
- 다이얼로그를 Compose로 이전
- SettingRow에 사용자 지정 가능한 후행 아이콘을 추가하고 앱 아이콘 처리를 개선
- UI 점검 및 최적화 작업

### 기능
- 고급 설정에 충전 중에만 켜기 필터 추가
- 피드백 페이지 추가
- 기능 테스트 페이지 추가

- Gradle을 8.9로, AGP를 8.7.3으로, Kotlin을 2.0.21로 업그레이드
- JDK 17로 이전
- 지원 중단된 API 이전
- Android 14/15 호환성 추가
- MMKV를 2.4.0으로 업그레이드(16KB 페이지 크기 지원)
- APK 서명과 자동 릴리스를 포함한 GitHub Actions CI/CD 워크플로 추가
- 라이선스를 MIT에서 GPLv3로 변경
