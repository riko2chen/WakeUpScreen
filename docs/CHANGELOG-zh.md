# 更新日志

WakeUpScreen 各版本的主要变更记录。

---

## [4.0.0]

### 新增
- 首页显示上次成功唤醒于多久之前（刚刚 / 分钟 / 小时 / 天），数据直接来自通知日志，点击可打开日志
- 睡眠时段支持按星期几生效，提供「每天 / 工作日 / 周末」快捷预设。跨午夜的时段归属于开始的那晚：周五 23:00 - 07:00 依然覆盖周六早晨。已有时段保持每天生效
- 新规则「低电量静默」：电量低于所选阈值（5-50%）且未充电时，通知不再亮屏；充电中始终放行
- 新规则「面朝下静默」：手机屏幕朝下扣放时通知不亮屏。由加速度计判断，与口袋模式使用距离传感器是同一套机制
- 「夜间红光」：睡眠时段内可选择短暂显示微弱红光（最低亮度、黑色背景），不再完全黑屏，适合值班、育儿等需要夜间待命的场景。选红色是因为它对暗适应视觉的干扰最小；在日志中以独立状态记录
- 注意力统计：完全在本机进行，仅基于两个事件——屏幕被唤醒、以及半分钟内是否解锁——统计最近 30 天哪些应用频繁亮屏却从不被理会，并对最严重的应用提供一键加入黑名单。不读取任何通知内容
- 设置支持导出为 JSON 文件、在其他设备导入，走系统文件选择器，不新增权限。文件格式带版本号：旧版本会忽略它不认识的新设置项，来自更新格式的文件会被明确拒绝并提示，而不是导入一半
- 应用内更新日志：更新后首次打开会弹出简短的更新摘要，跨版本更新时逐版本列出，不只显示最新一版。也可随时从「设置 → 关于 → 更新日志」查看；更新新增的设置项会带一个小圆点提示，点开后消失

### 变更
- 两条新规则与其他规则一样，出现在通知判断过程图示和通知日志中
- 精确亮屏时长到点熄屏前会先确认键盘锁还在：如果你在窗口期间已经解锁（或锁屏方式设为「无」），窗口直接结束、不再锁屏。此前解锁广播偶发丢失的机型上，可能在使用中被锁屏
- 精确亮屏时长的最短档从 3 秒改为 5 秒。上面的键盘锁检查需要避开部分机型唤醒初期的误报窗口；已保存的更短设置会自动抬升到 5 秒

### 说明
- 未新增任何权限
- 本版本保存的睡眠时段若未限制星期，3.2.0 仍可读取；限制了星期的时段在旧版本中会被丢弃而不是误读

## [3.2.0]

### 新增
- 睡眠模式支持多个时段。可以分别添加、删除，例如夜间一段、午休一段
- 睡眠时段精确到分钟，不再限制为整点
- 睡眠时间页新增 24 小时圆环，睡眠时段在环上置灰，并标出当前时刻。环上标有 0、6、12、18 四个刻度
- 添加时段时会检查与已有时段是否重合，重合会指出具体是哪一段并阻止添加

### 变更
- 配色按 Material 3 重做。颜色不再逐个手写，而是由品牌色生成整套色阶，浅色和深色分别取各自规定的档位，因此两套配色不会再出现一边调好、另一边错位的情况
- 顶部栏去掉渐变，改为纯色。状态栏颜色与图标明暗跟随当前页面：首页顶部仍是深色渐变，其余页面跟随浅色或深色主题
- 卡片、搜索框、顶栏之间改用 Material 3 的表面层级区分，深色下不再和背景糊成一片
- 24 小时圆环标出全部 0 到 23 时，此前只标 0、6、12、18，例如 02:00 - 04:00 到 03:59 为止。两个时段因此可以首尾相接，一段的结束时间正好是下一段的开始时间
- 原有的单个睡眠时段会在升级后自动转换为一个时段，行为不变
- 「持续通知优化」改名为「拦截持续通知」，「严格的持续通知过滤」改名为「拦截常驻通知」。两个开关的标题后增加问号按钮，点开说明各自拦什么、区别在哪
- 设置页重新分组为「通用」「高级」「诊断」「关于」。通用放语言和新增的深色模式；高级放通知判断过程和亮屏规则页；诊断放亮屏测试和日志入口
- 新增深色模式，可选跟随系统、浅色、深色三种。默认跟随系统，升级后外观不变
- 亮屏时长和应用过滤（模式、白名单、黑名单）从设置首页移入亮屏规则页，该页现在集中了所有决定亮不亮屏的设置
- 部分条目改名，让名字直接说明用途：「高级设置」改为「亮屏规则」，「拦截链路」改为「通知判断过程」，「功能测试」改为「亮屏测试」，「当前模式」改为「过滤模式」。仅改显示名称，所有设置项的值保持不变

### 修复
- 修复「严格的持续通知过滤」（设置 → 亮屏规则）写错配置项的问题：开关这一项实际改动的是普通的「常驻通知检测」，而严格过滤本身从未被保存 —— 每次重新进入页面都会变回开启状态。现在两个开关互相独立，也能正常保存

### 说明
- 修复前严格过滤实际上始终生效，修复后默认仍为开启，升级不会改变通知过滤行为
- 如果曾经拨动过严格过滤开关，普通的「常驻通知检测」可能已被一并改动，建议到「设置 → 亮屏规则」确认两个开关的状态

## [3.1.1]

### 变更
- 目标 API 升级到 Android 16（API 36）。已在 Android 16 系统镜像上验证：精确亮屏时长、无障碍锁屏动作、以及无需权限的兜底熄屏方式，行为与之前完全一致
- 二级页面的返回动画改为 Android 的预测式返回动画，不再使用应用自带的滑动过渡。这是适配 Android 16 后由系统接管的效果，仅影响观感，返回逻辑本身没有变化

### 说明
- 未新增任何权限，功能没有变化
- 已在使用 16 KB 内存页的设备镜像上验证可正常运行

## [3.1.0]

### 新功能
- 新增「重复提醒」（设置 → 高级设置）：只要通知还没处理，屏幕每隔 5～60 分钟再次亮起，通知被清除后立即停止。间隔与同一批未读通知的最多提醒次数均可调整；睡眠模式、免打扰、口袋模式、仅充电时亮屏、应用筛选的优先级仍然更高，常驻通知不计入未读
- 提醒亮屏会记入通知日志；功能测试可立即执行一次提醒，无需等待整个间隔
- 新增「自定义亮屏时长」（设置 → 自定义亮屏时长）：屏幕保持点亮 3、5、10、15 或 30 秒后主动熄灭，不再交还给系统的「屏幕超时」。熄屏通过系统自带的「锁定屏幕」动作完成，需要一个可选的无障碍服务，该服务不读取任何屏幕内容

### 变更
- 自定义亮屏时长默认关闭，关闭时不做任何事，已安装用户的行为与之前完全一致 —— 旧实现在获取唤醒锁后立即释放，配置的秒数本就从未生效

### 说明
- 未新增任何权限。提醒使用非精确闹钟，Doze 休眠可能让某次提醒晚几分钟到达
- 计时期间若解锁设备或屏幕提前熄灭，计时立即取消；通话过程中不会强制熄屏

## [3.0.6]

### 变更
- 移除 `FOREGROUND_SERVICE_SPECIAL_USE` 权限。点亮屏幕依赖通知监听服务，该服务由系统自动绑定保活，核心功能本就不需要这个特殊用途的前台服务。
- 移除可选的「常驻通知（保持服务存活）」设置，它是唯一用到该权限的功能。在激进管理后台的机型上，请改为将本应用加入电池优化白名单以保证可靠性。
