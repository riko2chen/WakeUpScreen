# 更新日志

WakeUpScreen 各版本的主要变更记录。

---

## [3.2.0]

### 修复
- 修复「严格的持续通知过滤」（设置 → 高级设置）写错配置项的问题：开关这一项实际改动的是普通的「常驻通知检测」，而严格过滤本身从未被保存 —— 每次重新进入页面都会变回开启状态。现在两个开关互相独立，也能正常保存

### 说明
- 修复前严格过滤实际上始终生效，修复后默认仍为开启，升级不会改变通知过滤行为
- 如果你曾经拨动过严格过滤开关，普通的「常驻通知检测」可能已在你不知情的情况下被改动，建议到「设置 → 高级设置」确认一下两个开关的状态

---

## [3.1.1]

### 变更
- 目标 API 升级到 Android 16（API 36）。已在 Android 16 系统镜像上验证：精确亮屏时长、无障碍锁屏动作、以及无需权限的兜底熄屏方式，行为与之前完全一致
- 二级页面的返回动画改为 Android 的预测式返回动画，不再使用应用自带的滑动过渡。这是适配 Android 16 后由系统接管的效果，仅影响观感，返回逻辑本身没有变化

### 说明
- 未新增任何权限，功能没有变化
- 已在使用 16 KB 内存页的设备镜像上验证可正常运行

---

## [3.1.0]

### 新功能
- 新增「重复提醒」（设置 → 高级设置）：只要通知还没处理，屏幕每隔 5～60 分钟再次亮起，通知被清除后立即停止。间隔与同一批未读通知的最多提醒次数均可调整；睡眠模式、免打扰、口袋模式、仅充电时亮屏、应用筛选的优先级仍然更高，常驻通知不计入未读
- 提醒亮屏会记入通知日志；功能测试可立即执行一次提醒，无需等待整个间隔
- 新增「自定义亮屏时长」（设置 → 自定义亮屏时长）：屏幕保持点亮 3、5、10、15 或 30 秒后主动熄灭，不再交还给系统的「屏幕超时」。熄屏通过系统自带的「锁定屏幕」动作完成，需要一个可选的无障碍服务，该服务不读取任何屏幕内容

### 变更
- 自定义亮屏时长默认关闭，关闭时不做任何事，已安装用户的行为与之前完全一致 —— 旧实现在获取唤醒锁后立即释放，配置的秒数本就从未生效

### 说明
- 未新增任何权限。提醒使用非精确闹钟，Doze 休眠可能让某次提醒晚几分钟到达
- 计时期间若解锁设备或屏幕提前熄灭，计时立即取消；通话过程中不会强制熄屏

## [3.0.6]

### 变更
- 移除 `FOREGROUND_SERVICE_SPECIAL_USE` 权限。点亮屏幕依赖通知监听服务，该服务由系统自动绑定保活，核心功能本就不需要这个特殊用途的前台服务。
- 移除可选的「常驻通知（保持服务存活）」设置，它是唯一用到该权限的功能。在激进管理后台的机型上，请改为将本应用加入电池优化白名单以保证可靠性。

---
